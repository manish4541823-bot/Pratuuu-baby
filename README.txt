CUTE GIFT WEBSITE 💗

Files:
- index.html : main page
- style.css  : cute responsive styling + animations
- script.js  : gifts, secret note, mini-game and flower effects
- assets/our-photo.jpeg : your uploaded photo

HOW TO USE:
1. Extract the ZIP.
2. Keep all files/folders together.
3. Open index.html in your phone browser or computer browser.
4. For best phone use, you can open the extracted folder with any simple local HTML preview app.

No build step or internet connection is required for the website itself (Google Fonts are optional; system fonts are used as fallback).
The design fits within one screen, with no page scrolling. The letter content panel can scroll only if a very small screen needs it.
